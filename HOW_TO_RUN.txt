HOW TO RUN (Windows, VS Code terminal)

1. Copy .env.example to a new file called .env and paste your GitHub token in it.

2. Set up Python (once):
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt

3. Run in this order:
   python step1_fetch.py      -> downloads issues (a few minutes)
   python step2_prepare.py    -> labels, PR check (~1 hour first time), cleaning, split
   python step3_check.py      -> checks the data is clean
   python step4_train.py      -> trains the first models

If a step stops, run the same command again: finished parts are skipped.
